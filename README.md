# Room → .set

Веб-приложение для телефона: фото комнаты → приватный репозиторий сканов → анализ → `scene.json` → `.set` для set.a.light 3D V3.
Запись `.set` выполняется в браузере (Pyodide, тот же Python-код, что и на Mac). Токен GitHub хранится только на устройстве.
Исходные данные (фото) в этот репозиторий не попадают — только в приватный `room-scans`.
